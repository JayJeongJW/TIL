# 2026-10-25 QA 수업 정리 — 게임 분석서 피드백 및 기획서 리딩 실습

> 개인 강의 필기 및 실습 기록. 강사 안내·피드백, 개인 플레이 소감, 향후 검증할 분석 가설을 구분한다.

## 1. 오늘 수업 핵심

- **게임 분석서:** 먼저 분석할 콘텐츠와 주제를 정하고, 문제점 → 근거 → 원인 추적 → 개선안 → 결론으로 논리를 구성한다.
- **PPT 피드백:** 한 페이지에 한 가지 핵심 메시지를 담고, 설명보다 수치·화면·근거를 명확히 보여준다.
- **기획서 리딩:** 교육용 **펫 시스템 기획서**를 읽고, 상세명세서를 작성하기 전 **자유 형식으로 기획 의도·규칙·예외 상황을 문의하는 연습**을 했다. 상세명세서는 아직 작성하지 않았으며 다음 주에 이어서 배우기로 했다.

## 2. 데이브 더 다이버: In the Jungle — 개인 산문

> 아래는 본인이 플레이하면서 느낀 점을 정리한 산문이다. 개발사의 의도나 객관적 결함으로 확정한 내용은 아니다.

데이브 더 다이버 본편을 재미있게 했던 이유는 바다에 들어가 다양한 생물들을 수집하고, 얻은 재료로 음식을 만들어 판매하면서 돈을 벌고, 그 돈으로 장비나 식당에 투자해 조금씩 성장하는 재미가 있었기 때문이다.

이번 정글 DLC도 그런 재미를 기대했는데, 막상 플레이해 보니 생각보다 수중 탐험의 규모가 작고 수집할 수 있는 생물도 다양하지 않게 느껴졌다. 정글이라는 새로운 배경이나 턴제 RPG가 추가된 것은 신선했지만, 각각의 콘텐츠를 충분히 즐기기도 전에 다음으로 넘어가거나 스토리가 끝나는 느낌이었다. 엔딩을 봤을 때도 뭔가 이야기가 더 이어질 것 같은데 갑자기 끝나버린 듯한 아쉬움이 남았다.

특히 미니게임이 너무 많다는 생각이 들었다. 본편에도 여러 미니게임이 있었지만, 이번 DLC에서는 다이빙과 식당 운영보다는 미니게임이나 주민들과의 상호작용에 더 많은 비중을 둔 것처럼 느껴졌다. 여러 장르를 섞어 새로운 재미를 주려는 것 같기는 한데, 오히려 이것저것 조금씩 맛만 보고 끝나는 느낌이 강했다. 개인적으로는 미니게임을 더 늘리기보다 기존의 다이빙과 수집을 좀 더 깊게 확장했으면 어땠을까 싶었다.

식당 운영과 성장 부분도 아쉬웠다. 본편에서는 새로운 재료를 얻고 음식을 개발하거나 수익을 투자하면서 식당이 성장한다는 느낌이 있었는데, DLC에서는 재료를 모으고 판매해 돈을 벌어도 그다음에 무엇을 위해 계속 돈을 벌어야 하는지 동기가 약하게 느껴졌다. 하우징도 꾸미는 재미는 있지만, 돈과 시간을 투자한 것에 비해 만족감이나 성취감은 크지 않았다.

결국 새로운 콘텐츠는 여러 가지 추가됐지만, 내가 본편에서 좋아했던 다이빙과 수집, 식당 경영의 재미는 오히려 줄어든 것 같았다. 콘텐츠의 규모가 작아서 그런 건지, 각각의 콘텐츠가 충분히 연결되지 않아서 그런 건지는 아직 잘 모르겠다. 다만 이것저것 할 일은 많은데 정작 하나를 깊게 즐기거나 성장시켰다는 느낌은 부족했다.

그래서 이번 DLC는 단순히 콘텐츠가 적다는 문제보다는, **여러 콘텐츠를 추가하는 과정에서 본편의 재미와 성장하는 성취감이 상대적으로 약해진 것은 아닐까** 하는 생각이 들었다.

## 3. 게임 분석서 — 테마와 구성

### 수업에서 안내한 흐름

1. **콘텐츠와 테마 선정**: 무엇을 분석할지 정한다.
2. **주제 설정**: 어떤 기준과 관점으로 내용을 전개할지 정한다.
3. **문제점 도출**: 구체적인 문제를 최소 3가지 제시한다.
4. **근거 수집**: 실제 게임 화면, 수치, 기존·현재 상태의 비교로 문제를 뒷받침한다.
5. **원인 역추적**: 현상에 바로 개선책을 붙이지 않고, “왜 이런 일이 발생했는가?”를 반복해 원인을 찾는다.
6. **개선 방안**: 문제별로 대응하는 개선안 **최소 3개 이상**을 제안한다.
7. **결론**: 분석 결과와 개인의 판단을 정리한다.
8. **Gamma 활용**: 분석 내용이 갖춰진 뒤 PPT 구성과 시각화에 AI를 활용한다.

수업에서 제시된 구성 예시: **타이틀(주제) → 문제점 및 근거 → 개선 방안 1·2·3 → 결론**. 예시를 그대로 복제하기보다는 문제와 원인의 연관성이 드러나도록 구성한다.

### 원인 분석의 관점

- ‘재료 수집이 어렵다’는 주장이라면 **어떤 재료를, 어떤 조건에서, 왜 어렵게 느끼는지** 밝혀야 한다.
- 식당 운영이 어렵다고 한다면 **구체적으로 어느 기능이나 과정에서 문제가 발생하는지** 제시해야 한다.
- 본편과 DLC를 비교한다면 **기존에는 어떠했고 현재는 무엇이 다른지**, 동일 기준의 데이터와 증빙을 확보해야 한다.
- 미니게임이 늘었다는 현상 자체보다 **그 변화가 핵심 플레이 경험에 어떤 영향을 주는지** 논리적으로 설명해야 한다.

## 4. 초안 PPT 피드백

### 전체 평가

- 대학 프로젝트 과제처럼 보이는 형태라는 피드백을 받음.
- 글이 많고 페이지를 채우는 데 집중되어 핵심이 눈에 들어오지 않음.
- 제목이나 결과에서 **정확히 어떤 문제를 다루는지** 드러나지 않음.
- 개인이 선택한 테마·주제를 분명히 정하기 전에 문제점과 개선안부터 나열하는 경향이 있음.

### 표지·슬라이드 개선 기준

| 항목 | 강의 메모 및 피드백 |
| --- | --- |
| 표지 | 불필요한 이미지는 제거하거나 최소화. **작성자와 분석 주제·문제의식**이 가장 먼저 보여야 함 |
| 제목 | 모호한 질문보다 **구체적으로 무슨 문제를 분석하는지** 명시 |
| 각 페이지 | 한 페이지의 핵심 키워드·메시지 명확히 |
| 근거 | 수치·기존 대비 변화·실제 화면·자료 출처 명시 |
| 본문 | 글로 가득 채우지 않고 핵심 문장과 시각 자료 중심 |
| 색상 | **3가지 이내** 권장; 지나치게 어둡거나 강한 색 피하기 |
| 폰트 | 정보 위계에 맞게 크기 조절, 읽기 편하게 구성 |
| Description | 장황한 설명은 최소화하거나 불필요하면 제외 |

### 강사님이 제시한 문제점 예시

1. **재료 수집 및 레스토랑 운영의 어려움** — 실제로 어려운 지점과 이전·현재 차이를 확인해야 함.
2. **다양한 미니게임으로 인한 재미 요소 반감** — 본편의 다이빙·재료 수집·레스토랑 운영에 비해 다른 장르의 미니게임이 크게 느껴지는 이유를 분석해야 함.

위 표현은 **수업 중의 검토 예시**이며, 실제 DLC의 결함으로 확정한 것은 아니다.

## 5. 기획서 리딩 실습 — 펫 시스템

이번 시간에는 **펫 시스템 교육용 기획서(Excel)**를 참고해 기획서의 규칙을 읽고, 이해가 부족하거나 명확하지 않은 부분을 **자유로운 형태로 문의하는 연습**을 잠깐 진행했다.

- 아직 상세명세서나 정식 TC를 작성한 단계는 아님.
- 정해진 상세명세서 양식에 맞추는 것보다 **기획서에서 의문이 발생하는 지점을 찾아 질문으로 표현하는 연습**이 우선이었음.
- 규칙·조건·예외·동작 결과가 모호하면 임의로 정답을 만들어 쓰지 않고 기획자에게 확인할 질문으로 남기는 접근을 배움.
- **다음 수업**에 이 작업을 이어서 마무리하며 상세명세서 작성 방법을 학습할 예정.

> 교육용 엑셀 파일 자체는 GitHub에 업로드하지 않았다. 파일 내용을 근거로 한 세부 규칙이나 실제 작성하지 않은 문의 사례는 이 TIL에 임의로 추가하지 않는다.

## 6. 오늘 수업을 통해 정리한 분석 관점

개인 산문의 출발점은 ‘미니게임이 많고 다이빙 콘텐츠가 적게 느껴졌다’는 경험이다. 그러나 **개인의 체감과 객관적인 콘텐츠 수량·구조는 구분**해야 한다.

향후 분석서는 다음과 같은 세 영역을 중심으로 구성할 수 있다.

| 검토 영역 | 분석 질문 |
| --- | --- |
| 탐험·수집 | 본편 대비 DLC에서 만나고 수집하는 생물과 탐험 콘텐츠의 규모·활용이 어떻게 달라졌는가? |
| 미니게임 | 본편에도 있던 미니게임이 DLC에서 어떤 장르·빈도·방식으로 나타나며 핵심 경험에 어떤 영향을 주는가? |
| 성장·하우징 | 장비·재료·재화를 투자한 이후 체감할 수 있는 보상과 후속 목적이 충분한가? |

이 내용은 **개인 분석의 검토 방향**이며, 정확한 원인과 개선안을 확정하려면 플레이 기록·공식 자료·이용자 의견을 검증해야 한다.
